# Gestor de base de datos
## Iniciar programa
- Asegurarse de estar en la misma conexion de la DB
- Para ejecutar el programa clickear el archivo `app.exe` que se encuentra en la carpeta `dist/` (Se puede generar un acceso directo para no tener que ingresar siempre a la carpeta)
- Para generar el acceso directo solo hacer click derecho sobre el archivo ejecutable y buscar la opcion de crear acceso directo, mover el acceso directo donde necesite y ejecutar.
## Cerrar programa
Se va abrir una consola al ejecutar el programa, si se quiere cerrar el programa por completo presionar `Ctrl + C` en la consola o sino simplemente cerrar la ventana de la consola.
